# Historical Contract Test Archive

These are the pre-reconciliation copies of the 30 tests processed during Phase 5.5C-V.3.

They are preserved as historical evidence. They are not current test authority.

Current runtime/backend assertions from 27 tests were migrated into the active test files. Three tests (Patch 43, Patch 52, Patch 53) were archived because their primary purpose was validating superseded documentation/tooling contracts rather than current product behavior.

Do not restore these files to make the active suite green.
