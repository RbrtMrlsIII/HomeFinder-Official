# HomeFinder — Checkpoint Structure

Status: **LIVING / DEVELOPMENT HYGIENE**

`active_development/` is the only active source tree.
`05_source_review/` is historical forensic evidence.
`reconciliation/` contains recovered census/mapping artifacts.
`03_authority_docs/` contains restored security/integration authority.
`04_recovery_archives/` contains sealed recovery archives.
`audit_phase*/` and `pov_phase/` contain audit/reconciliation evidence.

No new active document should be placed at the archive root. New authority or design decisions belong in `docs/`; structured machine-readable mappings belong in `data/`.
