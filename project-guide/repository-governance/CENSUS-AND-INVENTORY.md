# HomeFinder E3 — Census & Inventory Protocol

## Purpose

Provide one project-wide, source-first census that lets an executor see the current HomeFinder structure before transforming it.

This is an inventory capability, not a new authority. Existing canonical manifests, contracts, dictionaries, SH3D census records, and gate evidence remain authoritative for the meanings they own.

## Required domains

The census reports, when applicable:

- repository files
- product/UI surfaces
- routes and HTML screens
- backend/API surfaces
- data models and canonical registries
- 3D/spatial artifacts
- authored cameras and existing model census
- GLB/GLTF/OBJ/FBX/USD assets
- textures
- browser tests and test fixtures
- CI/CD workflows
- documentation and evidence
- session traces
- builds/artifacts
- semantic dictionary entries
- configured forbidden-file findings

## Source-first rule

Count actual files and parse explicitly configured source registries where their schema is stable. Do not infer inventory from filenames when a canonical registry owns the entity.

For example, `active_development/data/dictionary.json` remains the semantic dictionary owner, while `active_development/3d/docs/model-census.json` remains the detailed authored-model census.

## Inventory before transformation

Before a structural conversion, migration, rename, deletion, or generated-artifact promotion, capture a census baseline sufficient to compare before/after state.

The census is read-only with respect to project source. `--write` writes only census outputs under `.agent/census/` and `docs/census/`.

## Configuration

Machine configuration: `.agent/census/census.config.json`.

Executable: `scripts/census.py`.

Default exclusions: `.git`, `node_modules`, `dist`, `build`.

Forbidden patterns are configurable and are findings, not automatic deletion instructions.

## Validation

A valid census must be:

1. deterministic for the same checkout/configuration;
2. source-first and traceable;
3. explicit about missing/unparseable configured sources;
4. non-destructive to project source;
5. machine-readable and human-readable when written;
6. compatible with the existing HomeFinder documentation routing.

## Authority boundary

Census output is derived state. It must never override `HandOver.md`, `Endorsement.md`, canonical manifests, contracts, product knowledge, or the physical authority `master/HomeFinder.sh3d`.

## E3 completion rule

E3 is complete when the census tool, configuration, protocol, session trace, validation evidence, and whole-project handover are present and verified. Real project counts are generated by running the tool from a checked-out repository; no count is promoted from a partial API view merely because it looks plausible.
