## Session protocol
1. Read `README.md`.
2. Read `project-guide/AI_ASSISTANT_READ_ME.md`.
3. Read `HandOver.md`.
4. Read `Endorsement.md`.
5. Inspect relevant audits/contracts and the document routing map.
6. Choose the next applicable unchecked item.
7. Start a machine-readable session trace before substantive mutation.
8. Record each action and classify its impact as LOCAL, BOUNDED, or SYSTEMIC.
9. Make the smallest evidence-backed change.
10. Verify it independently.
11. Update only the canonical owners required by impact.
12. Mark the completed item `☑️` only when implementation, verification, documentation, and checkpoint inclusion are complete.
13. Update `HandOver.md`.
14. Keep detailed evidence in its designated `docs/` location.
15. Close the session trace with the result.
16. Do not create another handover file.
