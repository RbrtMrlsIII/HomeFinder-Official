# P04.4 Screenshot / Visual Review Specification — 2026-09-01

## Purpose
P04.4 evaluates fresh visual evidence from the already-validated P04 GLB runtime. It does not change product requirements, geometry authority, renderer behavior, or P04.3 assertions.

## Required target coverage
Capture fresh browser screenshots for the declared P04 visual targets represented by the existing target manifest: T02 Main Hall, T03 Kitchen, T03 Bedroom #1, T04 Staircase, and T05 Level 1 Interior.

## Review dimensions
- Renderer visibly mounted and canvas present.
- The selected target corresponds to the declared target ID.
- Model is visibly loaded rather than placeholder/mocked geometry.
- Camera framing and elevation are plausible against the existing source-backed contract.
- No obvious clipping, blank stage, broken textures, or runtime error state is visible.
- UI target selection remains legible and usable.

## Evidence discipline
Screenshots are evidence, not authority. Record the exact target, viewport, commit, and capture timestamp for each image. Any anomaly must be recorded rather than silently corrected.

## Boundary
P04.4 does not pre-accept P04.5 or P04.6. `master/HomeFinder.sh3d` remains protected. Do not weaken assertions or replace the established P04 browser mechanism.
