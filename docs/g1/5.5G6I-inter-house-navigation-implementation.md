## Architecture

The implementation uses **controlled logical transport**, not fabricated physical traversal.

`House 1 → House 2` and `House 1 → House 3` are valid controlled transitions.
`House 2 ↔ House 3` is forbidden directly. Cross-house journeys are routed through House 1.

## Security invariant

Travel never changes the authenticated role or identity. Destination access is evaluated through the existing route-access contract.
