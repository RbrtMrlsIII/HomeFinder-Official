## E3 project-wide census status

The new `scripts/census.py` is the canonical source-first project census tool. Its real checkout run must be performed from a checked-out HomeFinder repository with:

`python scripts/census.py --base . --write`

No project-wide numeric count is promoted into this baseline from a partial GitHub API tree response. This preserves the source-first rule and prevents fabricated inventory totals.

## Inventory domains implemented

The census schema covers repository files, HTML/UI surfaces, 3D assets, textures, tests, CI workflows, session traces, documentation, findings, and the existing semantic dictionary.

The tool is intentionally read-only against source artifacts. Census outputs are derived state.
